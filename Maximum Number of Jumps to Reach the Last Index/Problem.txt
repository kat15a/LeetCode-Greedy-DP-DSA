## Approach
- Use Recursion + Memoization (DP)
- From each index `i`, try jumping to every `j > i`
- A jump is valid if:

  abs(nums[j] - nums[i]) <= target

- Recursively find the maximum jumps from the next index
- Store computed results in `dp[]` to avoid recomputation

---

## Algorithm
1. Start from index `0`
2. If current index is `n-1`, return `0`
3. Check memoized result
4. Try all valid jumps
5. Take maximum among all possible paths
6. Store answer in `dp[]`
7. Return final result

---

## Complexity Analysis

Time Complexity:
O(n²)

Space Complexity:
O(n)
